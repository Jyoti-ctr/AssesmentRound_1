# Assessment Round 1 - Code Solutions

## Overview
This repository contains solutions to three fundamental programming challenges designed to assess algorithmic thinking and coding proficiency.

---

## Problems Included

### 1. Palindrome Check
**Description:** Determine whether a given string or number reads the same forwards and backwards.

**Example:**
- Input: `"racecar"` → Output: `true`
- Input: `"hello"` → Output: `false`

**Key Concepts:** String manipulation, two-pointer technique, recursion

---

### 2. Second Largest Element in Array
**Description:** Find the second largest distinct element in an array of numbers.

**Example:**
- Input: `[3, 1, 4, 1, 5, 9, 2]` → Output: `5`
- Input: `[10, 10, 10]` → Output: `null` (no second distinct largest)

**Key Concepts:** Array traversal, sorting, edge case handling

---

### 3. Word Frequency Counter
**Description:** Count the frequency of each word in a given text and return the results sorted by frequency.

**Example:**
- Input: `"hello world hello"` → Output: `{"hello": 2, "world": 1}`

**Key Concepts:** Hash maps/dictionaries, string parsing, sorting
